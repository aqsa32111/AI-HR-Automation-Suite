# Workflow 2 - AI Interview Scheduler

## Overview

This workflow automatically schedules interview invitations for shortlisted candidates.

## Features

- Receives candidate information
- Generates a professional interview invitation using AI
- Sends an email automatically
- Creates a Google Calendar interview event
- Shares interview details with the candidate

## Technologies

- n8n
- Groq AI
- Gmail
- Google Calendar
- JavaScript

## Workflow

Form Submission
↓
Generate Interview Email
↓
Format Email
↓
Send Gmail
↓
Create Google Calendar Event

## Result

Candidates automatically receive a professional interview invitation along with the scheduled interview details, while the interview is simultaneously added to Google Calendar.
