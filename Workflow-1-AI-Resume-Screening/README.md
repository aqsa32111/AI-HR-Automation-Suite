# Workflow 1 - AI Resume Screening

## Overview
This workflow automatically screens job applicants using AI.

## Features
- Accepts candidate information through a form
- AI analyzes the resume
- Calculates ATS score
- Generates recommendation
- Creates HR summary
- Stores all data in Google Sheets

## Technologies
- n8n
- Groq AI
- JavaScript
- Google Sheets

## Workflow
Form Submission
↓
AI Analysis
↓
ATS Score
↓
Recommendation
↓
Google Sheets

## Result
HR receives an AI-generated analysis of every candidate within seconds.
